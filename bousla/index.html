من نحن

«فهم راسخ» تطبيق يساعد ولي الأمر على تحويل صفحات الدرس إلى اختبارات ومراجعات، ومتابعة فهم أبنائه. للتواصل بشأن الخصوصية: vip1981.1@gmail.com.

البيانات التي نعالجها

  • حساب ولي الأمر: البريد الإلكتروني، معرّف الحساب، وعضوية الأسرة.
  • ملف الطالب: لقب يختاره ولي الأمر، المرحلة والصف الدراسي، وربط الجهاز؛ لا نطلب بريد الطالب أو تاريخ ميلاده أو مدرسته أو موقعه.
  • محتوى المستخدم: صور صفحات الدرس، النصوص والأسئلة، إجابات الطالب، قصاصات ورقة الإجابة، النتائج، مستويات المهارات، والخطط.
  • بيانات الاستخدام: الأفعال داخل التطبيق، حالة الجلسات والمهام، استخدام المساعدة، ومحاولات الربط وسجلات الأمان والحذف.

ترتبط هذه البيانات بحساب ولي الأمر وملفات أبنائه لتقديم وظيفة التطبيق وعزل كل أسرة. لا نستخدمها للتتبع الإعلاني، ولا نجمع الموقع أو جهات الاتصال أو معرّف الإعلانات.

أغراض الاستخدام

إنشاء الأسرة وربط جهاز الطالب، إنشاء الدروس والاختبارات، حفظ الإجابات وتصحيحها، متابعة المهارات، جدولة المراجعات، تقديم الشرح والتوصيات بعد موافقة ولي الأمر، حماية الحساب، تشغيل الاشتراك، وتنفيذ الحذف.

الذكاء الاصطناعي

تستخدم بعض الميزات Anthropic API لقراءة صفحات الدرس أو صياغة مسودات أسئلة وشرح وتقارير. يرسل الخادم فقط ما تحتاجه الوظيفة من: المقاييس المجمعة، مستويات المهارات، نصوص الأسئلة المعتمدة، صور صفحات الكتاب، وقصاصات خانات الإجابة.

لا نرسل عمداً الاسم الحقيقي أو البريد أو بيانات الأسرة أو أسماء الإخوة أو نتائج طفل آخر. قد تتضمن الصورة كتابة أضافها المستخدم؛ لذلك ننصح بعدم تصوير بيانات شخصية. وفق سياسة Anthropic المنشورة، تُحذف بيانات API خلال 30 يوماً في الوضع القياسي، مع الاستثناءات النظامية والأمنية. الذكاء الاصطناعي ينتج مسودات، بينما يحسب المحرك الحتمي الدرجات ومستويات المهارة ويعتمد ولي الأمر المسودات الإنشائية والخطط.

التخزين ومكان المعالجة

تخزن البيانات والملفات الخاصة في Supabase بمنطقة eu-west-2 (لندن). وقد تعالج Anthropic البيانات اللازمة خارج هذه المنطقة وفق شروطها. لا ندعي أن البيانات مخزنة أو معالجة داخل السعودية.

مدد الاحتفاظ

  • تبقى صفحات الدرس المعتمد حتى نهاية العام الدراسي الذي يحدده ولي الأمر، ما لم يطلب حذفها قبل ذلك.
  • تبقى بيانات الحساب والنتائج ومستويات المهارات وسجل التعلم ما دام حساب الأسرة نشطاً أو حتى تنفيذ طلب حذف صالح.
  • روابط الرفع والتنزيل قصيرة الصلاحية ولا تجعل الملفات عامة.
  • عند طلب حذف الأسرة يُلغى الوصول فوراً، والهدف التشغيلي لإكمال حذف الصفوف والملفات هو 72 ساعة.
  • قد تبقى نسخ احتياطية مشفرة لمدة محدودة وفق دورة مزود البنية التحتية ثم تُستبدل تلقائياً.

المشاركة

لا نبيع بيانات الطفل أو ولي الأمر. تقتصر المعالجة الخارجية اللازمة على Supabase للتشغيل، وAnthropic للميزات المذكورة، وRevenueCat وApple أو Google لإدارة الاشتراك، أو الإفصاح الذي يلزم به النظام.

الحذف

يمكن لولي الأمر طلب حذف حساب الأسرة من داخل التطبيق عبر: لوحة الأسرة ← أيقونة الخصوصية والحذف ← حذف حساب الأسرة ← كتابة «حذف الأسرة» ← طلب حذف الأسرة. يلغي الطلب وصول الأجهزة والجلسات فوراً ثم يحذف الخادم بيانات الأسرة وملفاتها. توجد التفاصيل في صفحة حذف الحساب.

حماية الأطفال

الحساب الإداري لولي الأمر، ووضع الطالب مقيد بربط جهاز يؤكده ولي الأمر وPIN وصلاحية قصيرة. التطبيق أداة تعليمية للأسرة وليس خدمة مستقلة موجهة للأطفال، ولا يعرض ترتيباً أو مقارنة بين الإخوة.
